# 🏢 DormHub — Система управління студентським гуртожитком

**DormHub** — це сучасна вебплатформа для автоматизації процесів поселення, обліку мешканців, оплати проживання та обслуговування кімнат у студентських гуртожитках закладів вищої освіти та коледжів.



## 🎯 Яку проблему вирішує система?

У більшості студентських гуртожитків процеси досі ведуться на папері або в розрізнених таблицях: черги під кабінетом коменданта під час поселення, загублені заявки на ремонт сантехніки чи електрики, плутанина з квитанціями про оплату та відсутність актуальної інформації про вільні місця.

**DormHub** переводить ці процеси в єдиний цифровий простір:
- усуває паперову бюрократію під час поселення та виселення;
- дозволяє студентам подавати заявки на ремонт або бронювання пральні за 1 хвилину зі смартфона;
- надає адміністрації прозору картину заповненості блоків, поверхів і кімнат у реальному часі.

## ✨ Основні функції

| Модуль | Можливості системи |
| :--- | :--- |
| **Облік ліжко-місць і поселення** | Інтерактивна шахматка поверхів і кімнат, електронна черга на поселення, автоматичний розподіл місць та генерація ордерів на поселення |
| **Заявки на ремонт (Helpdesk)** | Створення тікетів для сантехніка, електрика чи столяра з фото поломки, відстеження статусу виконання (`Нова`, `В роботі`, `Виконано`) |
| **Фінансовий облік та оплата** | Автоматичне нарахування плати за проживання та комунальні послуги, завантаження квитанцій, нагадування про заборгованість |
| **Побутові сервіси та графіки** | Онлайн-бронювання пральних машин, читальних залів і спортивних кімнат, графік чергувань на кухні та перевірок санітарного стану |
| **Електронна перепустка та гості** | Цифрова перепустка мешканця (QR-код) та попередня реєстрація відвідувачів у гостьовому журналі охорони |

## 👥 Для кого цей продукт?

1. **Студенти (мешканці та абітурієнти)** — подають онлайн-заяву на поселення, перевіряють баланс оплати, викликають майстра в кімнату, бронюють час у пральні та отримують оголошення від студради.
2. **Комендант та адміністрація гуртожитку** — керують номерним фондом, затверджують заявки на поселення/переселення, проводять інвентаризацію меблів і формують звіти для деканату.
3. **Технічний персонал (комендатура, майстри)** — отримують список актуальних заявок на ремонт із пріоритетами та відмічають їх виконання.
4. **Охорона (вахта)** — перевіряють цифрові перепустки мешканців і список погоджених гостей на сьогодні.
