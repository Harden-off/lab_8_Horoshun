# ⚙️ Довідник з інсталяції та запуску (`SETUP_GUIDE`)

Цей документ описує покроковий процес встановлення, налаштування та локального запуску вебплатформи **DormHub (Система управління гуртожитком)** для розробників, викладачів та системних адміністраторів.

## 🧰 Системні вимоги та необхідні інструменти

Перед початком розгортання переконайтеся, що на вашому комп'ютері встановлено такі інструменти:

| Інструмент / ПЗ | Мінімальна версія | Призначення |
| :--- | :--- | :--- |
| **Веббраузер** | Chrome 115+, Firefox 115+, Edge або Safari | Робота з клієнтським веб-інтерфейсом системи |
| **Git** | `2.35+` | Клонування репозиторію з вихідним кодом |
| **Node.js та npm** | `Node.js 18.x LTS` або вище | Запуск серверної частини та клієнтського застосунку |
| **SQLite / PostgreSQL** | `SQLite 3` (вбудовано для демо-режиму) | Локальне збереження бази даних кімнат, мешканців і заявок |
| **Обліковий запис GitHub** | Активний акаунт | Доступ до репозиторію проєкту |

## 📥 Покрокова інструкція зі встановлення та запуску

### Крок 1. Клонування репозиторію
Відкрийте термінал (або командний рядок у VS Code) та завантажте проєкт із GitHub:

```bash
git clone https://github.com/<ваш-логін>/documentation-lab-<прізвище>.git
cd documentation-lab-<прізвище>
```

### Крок 2. Встановлення залежностей
Встановіть необхідні бібліотеки проєкту за допомогою пакетного менеджера `npm`:

```bash
npm install
```

### Крок 3. Налаштування змінних середовища
Створіть конфігураційний файл `.env` у кореневій папці проєкту на основі шаблону `.env.example`:

```bash
cp .env.example .env
```

Перевірте базові параметри всередині файлу `.env`:

```ini
PORT=3000
DATABASE_URL="file:./dormhub_demo.db"
JWT_SECRET="dormhub-student-secret-key-2026"
DORM_NUMBER=4
```

### Крок 4. Ініціалізація демо-бази даних
Заповніть базу даних тестовими поверхами, кімнатами та демонстраційними профілями (комендант і студент):

```bash
npm run db:seed
```

### Крок 5. Запуск локального сервера
Запустіть застосунок у режимі розробки:

```bash
npm run start
```

Після запуску в терміналі з'явиться повідомлення:
`[DormHub Server] Система успішно запущена на http://localhost:3000`

## ✅ Перевірка роботи

Щоб переконатися, що система розгорнута та працює правильно, виконайте такі дії:

1. **Перевірка головної сторінки у браузері:**
   Відкрийте браузер і перейдіть за адресою `http://localhost:3000`. Має відобразитися стартова сторінка входу в **DormHub — Гуртожиток №4**.
2. **Перевірка тестового входу в систему:**
   Увійдіть під демонстраційним обліковим записом коменданта:
   - **Логін:** `admin@dormhub.edu.ua`
   - **Пароль:** `DormAdmin2026!`
   Якщо на екрані відкрилася панель зі статистикою вільних місць (наприклад: *«Зайнято 312 із 340 місць»*) та списком активних заявок на ремонт — клієнтська частина та база даних працюють справно.
3. **Перевірка працездатності API (Health Check):**
   Виконайте запит у терміналі або відкрийте у браузері адресу `http://localhost:3000/api/v1/health`:
   ```json
   {
     "status": "ok",
     "service": "DormHub API",
     "version": "1.2.0",
     "database": "connected"
   }
   ```
   Статус `"ok"` та `"database": "connected"` підтверджують повну готовність системи до роботи.
